---
name: ask-openclaw
description: Send one request to an explicitly selected OpenClaw conversation and follow its returned result.
---

Use Ask OpenClaw when the person asks OpenClaw to answer a question or do work.
Clarify the session when it is ambiguous. Keep the person's request intact and
send it once. Let OpenClaw request destination confirmation and any Gateway
approvals. A pending or unavailable reply is not permission to send again.
Use the returned continuation to open the accepted run's chat for full results.
Do not claim an external action succeeded unless the returned result establishes it.

---
name: talk-to-openclaw
description: Open a selected OpenClaw conversation for an authenticated live voice interaction.
---

Use Open Session Voice when the person asks to talk live with OpenClaw on iPhone.
Resolve the selected session first; clarify when the intended conversation is
ambiguous. This action uses that session's Gateway account and the app's existing
microphone permission and connection checks. Do not use the legacy current-chat
shortcut to bypass a failed selected-session action. For a one-off question that
should return text, use Ask OpenClaw instead.

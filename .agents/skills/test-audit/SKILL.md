# Test Audit

Authoring gates every new or changed test. Audits remove low-value proof in
coherent owner batches, not to meet deletion counts. For a whole-subsystem
campaign, read [CAMPAIGN.md](CAMPAIGN.md) first.

## Authoring gate

Before adding a test, answer:

1. What observable behavior, invariant, or independent contract does it protect?
2. What credible regression makes it fail?
3. Why does existing proof not catch it? Each contract has one primary owner at
   the strongest boundary. Another layer needs a distinct transport/lifecycle
   risk. Extend tables/shared fixtures and consolidate repeated setup.
4. Does it need an export, flag, wrapper, or injection hook with no production
   caller? Move proof to the real boundary instead.

Use the [boundary and cost guide](../../../docs/help/testing/writing-tests.md).
Regressions must fail on pre-fix code for the intended reason and pass after
repair; report unavailable baseline proof. One owner regression covers a bug;
do not replay it at every crossed layer. Behavior-preserving refactors should
not break the test.

## Junk patterns

Reject self-comparisons, copied inventories, source greps, implementation/call-shape
assertions, duplicate contracts, test-only seams, expected values generated by
the subject, and mocks that supply the behavior being asserted. Fixtures must
not fabricate owner receipts/order or claim persistence the path never writes.
Negative controls must fail at the intended guard; names must match exercised behavior.
Use the [full checklist](references/audit.md#junk-patterns) when auditing candidates.

## Retention bar

Keep independent API, SDK, protocol, config, migration, storage, security,
platform, default, prompt-byte, generated-language, package, release, architecture,
and observable-ordering contracts. Static or slow does not mean disposable.
Source inspection must survive identifier-only refactors and guard an independent
user-facing contract. Baseline failures may be bugs to repair, not tests to delete.

## Audit and validation

Before an audit edit, read [candidate evidence and workflow](references/audit.md#candidate-evidence):
inspect full owners/callers/history and record remaining proof before deletion.
Delete obsolete production seams with tests; never optimize for deletion counts.
Follow [proof policy](../openclaw-testing/SKILL.md#proof-policy), preserve active
Vitest checkouts, run owner/sibling proof and changed checks, then autoreview.
Report causes, retained contracts, proof/cost, production versus test LOC, and
follow-ups. Commit, push, or land only with task authority.

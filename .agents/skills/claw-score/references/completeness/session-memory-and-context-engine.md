# Session, memory, and state lifecycle Completeness

Use this rubric when assigning category Completeness scores for the
`session-memory-and-context-engine` surface.

## Category Scope

- CLI Session and Transcript Management: session listing and maintenance, transcript management, and trajectory export
- Token Management: compaction, pruning, token pressure, and recovery
- Context Engine: context discovery, artifacts, runtime assembly, and goal continuance
- Cross-client History and Session Parity: thread isolation, session continuity, Gateway-owned catalogs, and attachment
- Diagnostics, Maintenance, and Recovery: session diagnostics, restart recovery, verified backups and restores, and versioned state migrations
- Core Prompts and Context: instruction profiles, persona, artifacts, context visibility, and provenance boundaries
- Memory: memory storage, embedding search, active recall, provenance, promotion, exclusion, and forgetting
- Session Routing: session-key routing, conversation bindings, visibility, and model continuity
- Transcript Persistence: JSONL and provider transcript durability, redaction, locking, archive, retention, and repair

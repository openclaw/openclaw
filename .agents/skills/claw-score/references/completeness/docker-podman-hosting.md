# Fleet, containers, and cloud execution Completeness

Use this rubric when assigning category Completeness scores for the
`docker-podman-hosting` surface.

## Category Scope

- Container Setup: local Docker and Podman setup, isolated fleet-cell creation, cloud-worker profiles, and verified runtime bootstrap
- Container Operations: container targeting and hosting, fleet-cell lifecycle and diagnostics, and cloud-session dispatch, status, recovery, and teardown
- Image Release and Validation: container releases, release-path validation, prepared worker images, warm-image reuse, refresh, retention, and recovery
- Agent Sandbox and Tooling: Docker-backed agent sandboxes, dependency baking, cloud placement and machine admission, and authenticated cloud desktop control

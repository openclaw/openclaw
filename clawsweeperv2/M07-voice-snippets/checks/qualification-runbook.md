## Principal real-product flow

Use the accepted explicit command grammar with a synthetic trigger such as `greeting` and body `Hello, team.`; these are fixture values, not a claimed shipped syntax. In the built Control UI, establish a visible draft and selection, start the physical microphone, speak the command, and stop recording. Trace the real Gateway/provider final transcript into one review showing original source and literal expansion. Apply through the existing input owner, inspect text/selection, then invoke the actual editor's Undo. Confirm the accepted prior draft/metadata behavior and no message, Send request or agent run throughout capture, review, Apply and Undo.

**New source boundary:** current prose placement trims text, inserts spacing and uses `truncateUtf16Safe` against the editor's `maxLength`. The proposed literal path must preserve the complete accepted body or visibly refuse it while retaining recoverable text; a shortened snippet cannot count as success. UTF-8 catalogue byte limits and editor UTF-16 capacity are different measurements. Source inspection does not prove this future behavior.

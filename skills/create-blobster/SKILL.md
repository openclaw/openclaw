# Create a Blobster

Use this skill when a person asks to design, generate, customize, or update a Blobster mascot avatar or icon for an agent or Template in chat. Locate this `SKILL.md` and invoke `node <absolute-skill-directory>/scripts/cli.mjs` with an absolute path so rendering uses the running OpenClaw installation's bounded SVG/PNG renderer rather than hand-written `<svg>` files. Designing or previewing a Blobster is not permission to change a saved agent identity or publish a Template; apply identity or manifest updates only when requested.

1. **Choose a legible character concept.** Identify the agent or Template's role, tone, and one or two bold visual cues—one contrasting outfit shape and at most one held or worn prop—that remain readable at 24px sidebar and chat avatar size. Use existing `IDENTITY.md`, `SOUL.md`, or `CLAW.md` context before asking questions; ask one focused question only when the character direction is genuinely ambiguous. Complete when the palette (`shell`, `claw`, `glint`), outfit, and single prop are clear.
2. **Author the Blobster design JSON.** Follow [the Blobster design guide](references/design-guide.md) for exact lobster coordinates, layer clipping, and allowed SVG primitives. Keep `back` empty (`""`), leave the eyes at `(45, 32)` and `(75, 32)` unobstructed, keep clothing below the face inside `shell_overlay`, place held items in `left_prop` or `right_prop` so only the grip overlaps a claw, and prefer fewer than 20 shapes overall. Save the candidate JSON in a scratch or workspace design path without overwriting active avatars yet. Complete when the JSON matches `version: 1` and uses only static six-digit hex colors and allowed SVG shapes.
3. **Render and visually inspect the candidate.** Run `node <absolute-skill-directory>/scripts/cli.mjs agents render-blobster <design.json> --out <candidate.svg> --json` and also render `<candidate.png>` for visual inspection. If validation fails, fix the reported layer or attribute error in the design JSON and re-render; never bypass the CLI by writing raw `<svg>` markup directly. Follow the active image-reading tool's schema to inspect `<candidate.png>` at both full 256×256 resolution and tiny avatar scale: verify the rounded lobster silhouette, unobstructed eyes, clear contrast between outfit and shell, and clean prop placement. Revise and re-render if shapes clip awkwardly or crowd the face; state honestly if image inspection is unavailable in the current session. Complete when both `.svg` and `.png` render cleanly and pass visual review.
4. **Deliver or apply within explicit authority.** Show the preview through the conversation's supported attachment or preview path with its name and one-sentence description. Only when the person asks to apply the Blobster:
   - **For an agent:** write the approved file under the agent's workspace (for example `avatars/<id>.svg`), update `Avatar:` in `IDENTITY.md` when used, or run `node <absolute-skill-directory>/scripts/cli.mjs agents set-identity --agent <agent-id> --avatar avatars/<id>.svg --json`.
   - **For a local or draft Template:** place the SVG at `workspace/avatars/<id>.svg`, set `agent.identity.avatar: avatars/<id>.svg` and a matching `workspace.files` entry (`source: workspace/avatars/<id>.svg`, `path: avatars/<id>.svg`) in `CLAW.md`, and optionally render `assets/icon.png` for local package repositories.
     Complete when the person can inspect the finished Blobster and any explicitly requested agent or Template files are validated.

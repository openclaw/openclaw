# Create a Blobster

Use this skill when a person asks to design, generate, customize, or update a Blobster mascot avatar or icon for an agent or Template in chat ([#199162](https://github.com/openclaw/openclaw/issues/199162)). Locate this `SKILL.md` and invoke `node <absolute-skill-directory>/scripts/cli.mjs` with an absolute path so rendering uses the running OpenClaw installation's single canonical validator and SVG/PNG renderer rather than hand-written `<svg>` files that drift from the fixed lobster silhouette or emit disallowed elements ([#173762](https://github.com/openclaw/openclaw/pull/173762), [#181917](https://github.com/openclaw/openclaw/pull/181917), [#199162](https://github.com/openclaw/openclaw/issues/199162)). Designing or previewing a Blobster is not permission to change a saved agent identity or Template manifest; apply identity or manifest updates only when requested ([#196427](https://github.com/openclaw/openclaw/pull/196427), [#199162](https://github.com/openclaw/openclaw/issues/199162)).

1. **Choose a legible character concept.** Identify the agent or Template's role, tone, and one or two bold visual cues—one contrasting outfit shape and at most one held or worn prop—so tiny `24×24` sidebar and chat avatars stay readable instead of collapsing into detail noise ([#173762](https://github.com/openclaw/openclaw/pull/173762)). Use existing `IDENTITY.md`, `SOUL.md`, or `CLAW.md` context before asking questions; ask one focused question only when the character direction is genuinely ambiguous. Complete when the palette (`shell`, `claw`, `glint`), outfit, and single prop are clear.
2. **Author the Blobster design JSON.** Follow [the Blobster design guide](references/design-guide.md) as the single specification for lobster coordinates, layer paint order and clipping, and allowed SVG primitives ([#173762](https://github.com/openclaw/openclaw/pull/173762)). Write the candidate JSON to a scratch or candidate path first so failed iterations do not overwrite an active avatar ([#199162](https://github.com/openclaw/openclaw/issues/199162)). Complete when the JSON conforms to `references/design-guide.md`.
3. **Render and visually inspect the candidate.** Run `node <absolute-skill-directory>/scripts/cli.mjs agents render-blobster <design.json> --out <candidate.svg> --json` and render `<candidate.png>` for visual inspection ([#199162](https://github.com/openclaw/openclaw/issues/199162)). If validation fails, fix the reported layer or attribute error in the design JSON and re-render; never bypass the CLI by editing raw `<svg>` markup directly ([#173762](https://github.com/openclaw/openclaw/pull/173762), [#181917](https://github.com/openclaw/openclaw/pull/181917)). Because exit code `0` proves schema validity rather than visual legibility, inspect `<candidate.png>` with the active image-reading tool to verify unobstructed eyes, unclipped props within the `viewBox`, and clear shell-to-outfit contrast at `24×24` avatar scale; state honestly if image inspection is unavailable in the session ([#198229](https://github.com/openclaw/openclaw/pull/198229)). Complete when both `.svg` and `.png` render cleanly and pass visual review.
4. **Deliver or apply within explicit authority.** Show the preview through the conversation's supported attachment or preview path with its name and one-sentence description. Only when the person asks to apply the Blobster ([#196427](https://github.com/openclaw/openclaw/pull/196427), [#199162](https://github.com/openclaw/openclaw/issues/199162)):
   - **For an agent:** write the approved file under the agent's workspace (for example `avatars/<id>.svg`), update `Avatar:` in `IDENTITY.md` when used, or run `node <absolute-skill-directory>/scripts/cli.mjs agents set-identity --agent <agent-id> --avatar avatars/<id>.svg --json`.
   - **For a local or draft Template:** place the SVG at `workspace/avatars/<id>.svg`, set `agent.identity.avatar: avatars/<id>.svg` and a matching `workspace.files` entry (`source: workspace/avatars/<id>.svg`, `path: avatars/<id>.svg`) in `CLAW.md`, and optionally render `assets/icon.png` for local package repositories.
     Complete when the person can inspect the finished Blobster and any explicitly requested agent or Template files are validated.

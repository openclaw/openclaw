## 2026.11.1


### v2026.11.1

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.1).

This patch release has no new features. It improves managed Gateway service start messages and fixes problems that could interrupt Telegram and Discord conversations.

**Release scale:** 21 pull requests, 0 direct commits, and 4 contributors.

The pull request count includes backported source work.

#### Updates and Maintenance

- When starting the managed [Gateway](https://docs.openclaw.ai/cli/gateway) service, readiness messages now show more specific status, such as when the service stays stopped or the health check times out.
  See the [release backport](https://github.com/openclaw/openclaw/pull/190034). Thanks to [@RomneyDa](https://github.com/RomneyDa).

#### Messaging

- Fixes accepted [Telegram](https://docs.openclaw.ai/channels/telegram) messages sometimes receiving a false restart refusal or losing a fallback reply while they are processed.
  See [#179200](https://github.com/openclaw/openclaw/pull/179200), [#179385](https://github.com/openclaw/openclaw/pull/179385), and the [release backport](https://github.com/openclaw/openclaw/pull/190034). Thanks to [@steipete](https://github.com/steipete), [@LiuwqGit](https://github.com/LiuwqGit), and [@RomneyDa](https://github.com/RomneyDa).
- Fixes queued Telegram replies failing after an earlier conversation turn ends.
  See [#189457](https://github.com/openclaw/openclaw/pull/189457) and the [release backport](https://github.com/openclaw/openclaw/pull/190034). Thanks to [@vincentkoc](https://github.com/vincentkoc).
- Fixes accepted [Discord](https://docs.openclaw.ai/channels/discord) messages being refused while waiting to be processed.
  See [#179704](https://github.com/openclaw/openclaw/pull/179704) and the [release backport](https://github.com/openclaw/openclaw/pull/190034). Thanks to [@jalehman](https://github.com/jalehman).

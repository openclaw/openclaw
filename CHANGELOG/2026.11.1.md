## 2026.11.1


### v2026.11.1

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.1).

This patch release adds no new features. It fixes accepted messages being refused, failed Doctor inspections reported as successful, and Gateway configuration writes getting stuck.

**Release scale:** 83 pull requests, 91 direct commits, and 67 contributors.

The pull-request count includes source work brought in through backports, without counting backport wrappers twice. Direct commits include release adaptations.

## 2026.11.4


### v2026.11.4

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.4).

This is a patch release with fixes for problems that could skip buffered Signal messages after a reconnect, lose replies after a settings reload, or damage memory and configuration recovery copies. It also adds a delegated change approval setting and lets policy plugins inspect images before they reach a model.

**Release scale:** 99 source pull requests, 72 direct commits, and 69 contributors.

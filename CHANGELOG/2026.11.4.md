## 2026.11.4


### v2026.11.4

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.4).

This is a patch release with no new features. It fixes problems that could leave chats stuck, lose replies after a settings reload, or damage memory and configuration recovery copies, alongside smaller reliability fixes.

#### Installation and Onboarding

- Fixes private CLI launchers failing when npm install prefixes or Git checkout paths contain spaces or shell characters.
  [Released change](https://github.com/openclaw/openclaw/commit/76d4d82f6f081e621f47faa0d96ad46d5774b8c3). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Fixes the Windows PowerShell installer handing batch shims to onboarding without the system command interpreter. If launch fails, the installer shows a command to run onboarding manually.
  [Released change](https://github.com/openclaw/openclaw/commit/fbe819899c9e4b05350fe51fdc4f76b165bb8435). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Fixes macOS installation reporting Homebrew setup as successful and continuing provisioning after the Homebrew bootstrap fails. The original error and exit status are preserved.
  [Released change](https://github.com/openclaw/openclaw/commit/88eccb8e6b2288a3bcaf130f6858391735ca534a). Thanks to [@RomneyDa](https://github.com/RomneyDa).

#### Updates and Maintenance

- Reduces memory used by Doctor when repairing large SQLite transcript histories and lets interrupted repairs resume.
  [Released change](https://github.com/openclaw/openclaw/commit/25ba38e6ebf471f5f527841d855d5fd7484e65d1). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Fixes stable updates following saved prerelease tags for trusted official plugins. Previously selected tags are also affected, and the installed plugin is retained if no compatible stable version is available.
  [Released change](https://github.com/openclaw/openclaw/commit/9aede0c1e48fbc92c6ecdd37187eef8401e376ab). Thanks to [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa).
- Fixes configuration recovery losing accepted edits after a large formatting or size reduction, while keeping suspiciously truncated input out of the recovery baseline.
  [Released change](https://github.com/openclaw/openclaw/commit/e203db1f7da4e8f0825470f941422cdb5a9c4bf5). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Prevents a failed Doctor merge of legacy memory from truncating MEMORY.md and keeps recovery copies of the original files.
  [#190497](https://github.com/openclaw/openclaw/pull/190497), [Released change](https://github.com/openclaw/openclaw/commit/b70175def54e2adb8bc09ee01bf694fa8e815126). Thanks to [@syxscott](https://github.com/syxscott), [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa). See the [Doctor guide](https://docs.openclaw.ai/cli/doctor).
- Fixes startup and Doctor repair for older profile databases missing the login column, while preserving existing profile data.
  [Released change](https://github.com/openclaw/openclaw/commit/9b18491306f4ca7b377e902adc7a5929d2a8089a). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Prevents an interrupted pre-update configuration snapshot from damaging an existing rollback copy. The updater taking the snapshot must already include this fix, and the retained copy may be older.
  [Released change](https://github.com/openclaw/openclaw/commit/c73839039a8a60a081b9b6f643a7230271060236). Thanks to [@kaguranananana](https://github.com/kaguranananana), [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa).
- Fixes updates failing to finish after an unrelated configuration edit during plugin finalization, while preserving that edit. Resolve conflicts in the same fields before retrying update repair.
  [Released change](https://github.com/openclaw/openclaw/commit/7f8d87a58c032c13d82480b6dd7f6240c1aec772). Thanks to [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa).
- Prevents a newer CLI from migrating a database still used by an identified older Gateway service. If migration is refused, run openclaw update or use the service installation’s CLI. Service detection is best effort.
  [Released change](https://github.com/openclaw/openclaw/commit/5d91ea16dddcd2aa5171698d186ed06247a186c4). Thanks to [@shakkernerd](https://github.com/shakkernerd), [@RomneyDa](https://github.com/RomneyDa). See the [update guide](https://docs.openclaw.ai/install/updating).
- Fixes manual trimming of large session transcripts exhausting memory when only a small recent tail is kept.
  [Released change](https://github.com/openclaw/openclaw/commit/143b7a9567e4502e6dd6e673dc2ed2784f0f578a). Thanks to [@vincentkoc](https://github.com/vincentkoc), [@RomneyDa](https://github.com/RomneyDa).
- Fixes updates being blocked by an unsafe temporary-directory ancestor when the installed updater can use a safe private workspace in the state directory. An older updater may still need the temporary hierarchy repaired before its first update.
  [Released change](https://github.com/openclaw/openclaw/commit/4475c3af401135ce78824facd0374e9aa8f1cad4). Thanks to [@RomneyDa](https://github.com/RomneyDa). See the [update guide](https://docs.openclaw.ai/cli/update).
- Fixes PostgreSQL writes ignoring your configured commit durability. The bridge now inherits your PostgreSQL setting, which can increase write latency; choosing asynchronous commits can risk losing recent acknowledged writes after a crash.
  [#180821](https://github.com/openclaw/openclaw/pull/180821), [Released change](https://github.com/openclaw/openclaw/commit/d2c670d5ffbb209c7cc1a43556aaa951473160ef). Thanks to [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa).
- Fixes configuration changes getting stuck during a Gateway restart when plugin lifecycle work needs to finish. Restart deferral warnings also identify pending configuration preparation.
  [Released change](https://github.com/openclaw/openclaw/commit/79b61a94815ee2631db7fb13d0b04162035f588d). Thanks to [@RomneyDa](https://github.com/RomneyDa).

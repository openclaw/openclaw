## 2026.11.11


### OpenClaw v2026.11.11

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.11).

OpenClaw 2026.11.11 is a patch release focused on reliability across updates, backups, models, and messaging. It also resolves issues in memory, skills, apps, Web UI, plugins, and security.

**Release scale:** 100 pull requests, 34 direct commits, and 40 contributors.

#### Installation and Onboarding

- Fixes Docker Compose CLI config and channel commands failing while the Gateway is running by sharing the Gateway process namespace, and preserves saved Docker sandbox settings during setup upgrades. If you maintain a custom Docker Compose CLI service, share the Gateway process namespace alongside its network namespace too.
  Sharing the process namespace allows state writes from the CLI container to verify Gateway ownership.

  [#202288](https://github.com/openclaw/openclaw/pull/202288).

  Thanks [@deepujain](https://github.com/deepujain), [@sallyom](https://github.com/sallyom), [@RomneyDa](https://github.com/RomneyDa), and [@vincentkoc](https://github.com/vincentkoc).
- Fixes non-interactive Linux onboarding with `--install-daemon` modifying config, creating a workspace, or running `--reset` before failing when user-systemd services are unavailable.
  Onboarding now checks user-systemd availability up front and prompts you to rerun with `--skip-daemon` or retry from a working user-systemd session.

  [#204378](https://github.com/openclaw/openclaw/pull/204378).

  Thanks [@jjjhenriksen](https://github.com/jjjhenriksen).

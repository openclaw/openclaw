## 2026.11.10


### OpenClaw 2026.11.10

**Deep Research** brings a question, its report and its cited sources into the same conversation. Follow progress in the conversation, then open the sources behind the report. With the portable engine, you can check the quoted passages yourself.

**Before you upgrade**, [make a verified backup](https://docs.openclaw.ai/install/updating/rollback-and-recovery#before-updating-create-a-verified-backup) if you may need to return to 11.7. To go back after a database migration, restore that backup with its matching 11.7 release. Installing the old binary alone does not reverse the migration. If you use the LanceDB memory plugin, this release adds remediations for the certificate incident under root-only verification. If your self-hosted web search or fetch endpoint redirects to a different hostname, configure the destination hostname directly before upgrading.

##### Pair this browser


On the Control UI served by your Gateway, choose **Pair this browser** to request a code, then approve it on the host with `openclaw pair <code>`. Approve only a request you started. The browser gets administrator access, and Gateways that use identity-based roles still require sign-in.
[#191513](https://github.com/openclaw/openclaw/pull/191513).

Thanks [@daniel-lxs](https://github.com/daniel-lxs), [@jalehman](https://github.com/jalehman).




##### Agent Templates


With Templates enabled, you can preview a recommended agent’s files, skills, plugins and automations in chat before adding it. You can also preview a published ClawHub Template by name and see its version, requirements and trust warnings without installing anything. Adding it opens the new conversation without sending a message for you.

This needs Templates enabled in Labs, an eligible workspace on the Gateway host and an administrator connection through the Control UI. You review the proposal in the same chat. Thanks [@Patrick-Erichsen](https://github.com/Patrick-Erichsen).

##### OpenClaw ID remote access


With OpenClaw ID remote access enabled in Labs and its relay and sign-in services configured, you can reach your Gateway from an approved browser. As the owner, link it from the computer running OpenClaw and save the recovery kit when prompted. From **Access**, you can invite people or remove their access without sharing your own Gateway credentials.
[#192345](https://github.com/openclaw/openclaw/pull/192345), [#192352](https://github.com/openclaw/openclaw/pull/192352).

Thanks [@jalehman](https://github.com/jalehman).

Owners with a running relay and a compatible Discovery service can add a node. Create a private invitation and compare the six digits in **Access** with the ones on the node. Review the commands it requests before approving it. You can remove the node later from the same page.
[#194001](https://github.com/openclaw/openclaw/pull/194001), [#194007](https://github.com/openclaw/openclaw/pull/194007), [#197538](https://github.com/openclaw/openclaw/pull/197538).

Thanks [@jalehman](https://github.com/jalehman).

If the Gateway’s connection keys are lost or exposed, the owner can replace them on that computer using the recovery kit, an account link code and a compatible Discovery service. Your people and devices stay linked. Without the kit, you cannot move the Gateway to new keys this way.
[#196388](https://github.com/openclaw/openclaw/pull/196388), [#196456](https://github.com/openclaw/openclaw/pull/196456).

Thanks [@jalehman](https://github.com/jalehman).

#### Updates and Maintenance

Choose when automatic updates start, watch a backup progress and recover from an interrupted update without leaving the Gateway stopped.


##### Backup progress


When you create or verify a backup, you can see which stage is running and, where available, how many bytes or database pages it has processed. If the backup stops partway through, the summary distinguishes the stage it reached from the ones it finished.
If you request JSON output, progress goes to standard error so scripts can still read the result from standard output.

[#198675](https://github.com/openclaw/openclaw/pull/198675).

Thanks [@vincentkoc](https://github.com/vincentkoc).

You can create and verify a PostgreSQL backup without stopping the Gateway. Each store is captured at its own moment. Stop the Gateway first if you need one quiet point across stores, and always stop it before restoring.
[#185236](https://github.com/openclaw/openclaw/pull/185236).

Thanks [@etzelm](https://github.com/etzelm).




##### Automatic update schedules


Choose an hourly, daily, weekly or custom start time for automatic updates. The schedule follows the Gateway computer’s time zone and skips missed windows. It is a start time, not an installation deadline. Active work or a rollout delay can still postpone the update.
[#193713](https://github.com/openclaw/openclaw/pull/193713).

Thanks [@jacobtomlinson](https://github.com/jacobtomlinson).

#### Memory

In chat and through the Gateway, built-in memory search reads the published index and warns when known updates are pending. #### Models and Providers

MiniMax gains new image options and drops retired chat models. OpenClaw also gives you finer control over which models receive a request or a file.


##### MiniMax H3 image generation and editing


Choose `MiniMax-H3-Image` or `MiniMax-H3-Image-Highspeed` to generate an image from text or edit with up to 16 reference images. Both models support 1K, 2K and 4K output. If you keep the existing `image-01` default, its one-reference limit is unchanged.

## 2026.11.12

### Highlights

- **Live chats keep their place:** If you send another message while an agent is working, the first request can still get its answer after the agent replies to the second. (#206412) Related #202669 Thanks @obviyus and @Davidnovarro.
- **Codex keeps replying across turns:** Reused Codex workers deliver later answers without letting a late notification from an older turn finish the new one. (#206014, #206080) Thanks @freeqaz-openai.
- **Encrypted messaging:** Matrix delivers the first encrypted message after a Gateway restart, and WhatsApp keeps running if it cannot decrypt an attachment. (#206491, #206815) Related #206168, #206776 Thanks @imshirka, @obviyus, and @davidzuluaga5.
- **Gateway updates behind Tailscale:** Update health checks work when the Gateway is exposed through Tailscale Serve or Funnel. (#205443) Related #205405 Thanks @e-jung.
- **Safer Git updates:** Git-based updates can capture older databases during a 9.37 upgrade and reject incomplete backup commits instead of treating them as recoverable backups. (#205945, #206200) Related #205939, #206186 Thanks @daniel-lxs.
- **Scheduled tasks report real outcomes:** A scheduled task no longer reports success when the model only prints the requested tool call without executing it. (#206441).

### Changes

- **OpenAI models:** GPT-6.1 Terra is now supported in the OpenClaw runtime. (#207047) Thanks @vincentkoc.
- **Install channels:** A Git installation can switch back to the npm package using the supported updater. (#204835) Authored by @steipete. Thanks @RomneyDa.

## 2026.11.8


### OpenClaw v2026.11.8 release notes

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.8).

**Security release:** This patch prevents workspaces from redirecting credentialed Azure requests and keeps Signal view-once attachments out of agent conversations and OpenClaw’s inbound media storage.

OpenClaw 2026.11.8 fixes conversations losing their history or dropping the final answer after a tool call, a follow-up or an interrupted message. It also fixes missed automation updates, model sign-in failures and incomplete recovery backups.

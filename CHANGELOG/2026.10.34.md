## 2026.10.34

This extended-stable patch updates the Gateway and official npm plugins from 2026.10.33. It includes the core npm package and Gateway Docker images, but no native-app releases.

### Highlights

- OpenAI and ClawRouter: select GPT-6.2 Astra and Sol, with system-prompt caching on the OpenAI API-key and Sign in with ChatGPT Responses routes. (#200766, #201094) Authored by @steipete. Thanks @RomneyDa, @fuller-stack-dev, and @obviyus.
- Tlon: group DMs use their own approval policy, and approved clubs remain authorized across Gateway restarts. (#202775) Thanks @joshavant.
- Update recovery: avoid leaving the Gateway offline when an update runs alongside database readers or replaces a running checkout, and recover the service after a failed Windows update rolls back. (#201330, #202541, #203241, #203264) Authored by @steipete. Thanks @RomneyDa.
- Conversation continuity: deliver ready child results without waiting for other helpers to finish, and accept follow-up chat messages after the preceding run completes. (#203176, #203102, #201790) Authored by @steipete. Thanks @obviyus, @RomneyDa, and @vincentkoc.
- Channel delivery: recover Telegram polling when update IDs reset, keep an undownloadable attachment from blocking replies, and reconnect all Discord accounts after a network outage. (#201167, #200682, #201415, #162189) Thanks @RomneyDa, @obviyus, and @mattreyes0824.

### Changes

- MiniMax: stop offering retired M2 models, including during live discovery, and use MiniMax-M3 for PDF text extraction. If your configuration explicitly selects an M2 model, switch it to a supported model. (#203998) Thanks @RomneyDa.

### Fixes

- Access controls: apply the session permission mode consistently on Gateway tool calls, recheck bound Discord DMs against current policy, and keep Signal view-once attachments out of assistant context. (#202941, #196848, #196841) Thanks @obviyus and @drobison00.
- Channel setup: save new tokens through the channel secret store rather than writing them to config as plaintext. (#201428, #175333) Thanks @anmol0b, @sallyom, and @masatohoshino.
- Discord and Slack: queue independent Discord requests instead of replacing an active task, show when the target session is busy, and leave Slack question buttons available when a click comes from someone who cannot answer. (#201518, #201363, #201371, #201348) Authored by @steipete. Thanks @vincentkoc, @obviyus, and @shannon0430.
- Conversation delivery: return complete queued ACP replies, preserve Claude CLI final answers after progress messages, and avoid repeating tool work on a fallback model during long Claude CLI turns. (#202658, #200470, #200801, #200744) Thanks @obviyus, @chaeyn, @fede-kamel, and @jzmudzinski.
- Conversation recovery: resume saved requests when transcript metadata advances, and keep pending child results when the requesting run ends or a follow-up takes over. (#201477, #195275) Authored by @steipete. Thanks @RomneyDa and @jalehman.
- OpenAI and Codex: preserve session affinity for Sign in with ChatGPT and let Codex subagents start from agent folders with capital letters. (#197588, #197532, #201520, #201423) Thanks @sukhdeepjohar, @aatreya, @obviyus, and @thejeys19.
- Provider reliability: compact before predicted context overflow instead of trimming tool results already cached by the provider, stop retrying Anthropic requests that require credits, and preserve user-configured model rows on provider sign-in. (#199530, #201997, #201742, #201558) Authored by @steipete. Thanks @obviyus, @LinzeShi, @MertBasar0, and @Caitoz.
- Install and update: avoid hanging at NodeSource on Ubuntu 26.04, preserve pnpm-linked checkouts when switching to the npm release, and complete updates with read-only, unchanged config or old plugin leases. (#203538, #201701, #201331, #201314) Authored by @steipete. Thanks @fuller-stack-dev.
- Storage and backups: let large PostgreSQL maintenance operations finish, recover after silent database connection loss, port upgraded stores to PostgreSQL, and reclaim space when backup staging databases are deleted. (#201869, #201856, #201299, #201250, #199666) Thanks @VACInc, @chelsealong, @evemorgen, and @etzelm.
- Doctor: reuse the existing state database for offline update checks after backup, avoiding extra copies of large databases. (#202985) Authored by @steipete.
- Browser and Control UI: capture background tabs in headed or headless Chrome, keep final answers out of the collapsed Worked fold, and preserve pending dictation transcripts while showing progress. (#202878, #165312, #201626, #197429, #200235) Thanks @obviyus, @titan550, @Marvinthebored, @vyctorbrzezowski, @Peetiegonzalez, and @daniel-lxs.
- Automation and Feishu: deliver automation failure notices back to the chat that created the job and finish long replies in the same streaming card. (#203056, #161777, #139443) Thanks @obviyus, @ArthurNie, and @Simon2256928.

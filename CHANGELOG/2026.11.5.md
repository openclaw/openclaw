## 2026.11.5


### v2026.11.5

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.5).

OpenClaw 2026.11.5 includes bug fixes and quality-of-life improvements for sessions, updates, automations, tools and providers.

#### Quality of life

##### Chat and sessions

- Adds a keyboard link to skip the chat transcript and reach the message composer. In archived chats it leads to the footer and Unarchive.
  [#180896](https://github.com/openclaw/openclaw/pull/180896). Thanks to [@goutamadwant](https://github.com/goutamadwant), [@liuwqgit](https://github.com/liuwqgit), [@obviyus](https://github.com/obviyus) and [@carlopignatari-boop](https://github.com/carlopignatari-boop).
- Simplifies paired-device folder selection in New Session. Admins can browse, other writers can enter an absolute path, and the selected folder name appears in the workspace chip.
  [#190088](https://github.com/openclaw/openclaw/pull/190088). Thanks to [@obviyus](https://github.com/obviyus) and [@RomneyDa](https://github.com/RomneyDa).
- Adds global and per-agent limits for client-side compaction summaries. The default remains 16,000 characters; larger summaries use more context and cost more to replay.
  [#196207](https://github.com/openclaw/openclaw/pull/196207). Thanks to [@aniruddhaadak80](https://github.com/aniruddhaadak80), [@garrytan](https://github.com/garrytan), [@RomneyDa](https://github.com/RomneyDa) and [@vincentkoc](https://github.com/vincentkoc).
- Reduces JavaScript loaded when opening Chat by deferring the Template creator and workspace conflict recovery controls until needed.
  [#187783](https://github.com/openclaw/openclaw/pull/187783), [#187830](https://github.com/openclaw/openclaw/pull/187830). Thanks to [@vincentkoc](https://github.com/vincentkoc).
- Limits expansion when reading compressed conversation archives to reduce memory pressure. Archives that exceed the limit fail visibly; uncompressed JSONL is an alternative.
  [commit 2b08b6f](https://github.com/openclaw/openclaw/commit/2b08b6f7880ded69c626f5c63f087517c0802bcd). Thanks to [@RomneyDa](https://github.com/RomneyDa).

##### Tools and providers

- Adds a directory of eligible deferred MCP tools to Tool Search, so agents can discover listed tools without a separate search. Large catalogs may still require a search for omitted names.
  [#196252](https://github.com/openclaw/openclaw/pull/196252). Thanks to [@jalehman](https://github.com/jalehman), [@GrahamMcBain](https://github.com/GrahamMcBain) and [@RomneyDa](https://github.com/RomneyDa).
- Adds compact input signatures to MCP Tool Search results, helping agents make straightforward calls without requesting every full tool description. Complex or missing schemas may still need the full description.
  [#196266](https://github.com/openclaw/openclaw/pull/196266). Thanks to [@jalehman](https://github.com/jalehman), [@GrahamMcBain](https://github.com/GrahamMcBain) and [@RomneyDa](https://github.com/RomneyDa).
- Adds Gemini Decision 1 as a provider option for Boolean, choice and score evaluations of text, JSON or one supported image. It requires a Gemini Developer API key; evaluation sends evidence to Google and incurs API charges. This is not a chat or Vertex model.
  [commit 01b98da](https://github.com/openclaw/openclaw/commit/01b98da7d3dbcca5d26a6a970f1ab0438adfdcab). Thanks to [@RomneyDa](https://github.com/RomneyDa), [@vincentkoc](https://github.com/vincentkoc) and [@obviyus](https://github.com/obviyus).
- Adds a read-only GitHub publication readiness check so agents can inspect a session’s source and existing publication requests without starting a publication.
  [#187152](https://github.com/openclaw/openclaw/pull/187152). Thanks to [@fuller-stack-dev](https://github.com/fuller-stack-dev).

  [commit aea2145](https://github.com/openclaw/openclaw/commit/aea2145245226b1097c613ea872dc18fee5f8838). Thanks to [@RomneyDa](https://github.com/RomneyDa).

  [#193970](https://github.com/openclaw/openclaw/pull/193970). Thanks to [@steipete](https://github.com/steipete), [@karam2022](https://github.com/karam2022) and [@RomneyDa](https://github.com/RomneyDa).

  [commit baba5d8](https://github.com/openclaw/openclaw/commit/baba5d8b798ce71484e756c2e827913ea1f72f76). Thanks to [@RomneyDa](https://github.com/RomneyDa), [@vincentkoc](https://github.com/vincentkoc) and [@etzelm](https://github.com/etzelm).

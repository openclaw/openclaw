## 2026.10.5-beta.2

### Highlights

- **Updates unblock themselves:** `openclaw update` now settles stale handoff leases, completed receipts, and legacy 2026.9.8 recovery records instead of stopping on `update-recovery-pending`, keeps large-database Doctor runs within the service heap limit, and keeps webhook listeners through deferred plugin upgrades. (#169038, #169027, #168388, #168889, #169035) Thanks @mkdelta221, @waynegault, @chedong, @k94118, @bluet, and @sirius1024.

### Changes

- **Update performance:** updates stop rehashing unchanged runtime files while retaining the running updater and publishing the candidate, reducing update I/O. (#168958)

### Fixes

- **Doctor recovery copies:** Doctor and updater recovery copies now include legacy Canvas documents and Memory Core host-event and sidecar files before their migrations move or delete them, so rollback can restore them. (#169436) Thanks @RomneyDa.
- **Replies during startup:** new replies wait for their agent to finish starting instead of failing with `prepared reply dispatch runtime owner was not published`, while ready agents keep serving. (#168826, #157814) Thanks @xiaozishan.
- **Model fallback:** scheduled and ordinary agent turns reach the configured fallback model after a primary provider timeout instead of failing with a transcript-version error. (#168605)
- **Model catalog memory:** a long-running Gateway's model-catalog worker evaluates an unchanged installed native ESM plugin once per workspace instead of retaining another copy of its module graph on every config change, and a failed native refresh re-registers the requested config on the next request. (#169272, #169321, #159662) Thanks @obviyus, @mcooks-cmd, @RomneyDa, and @svdinu-jpg.
- **Telegram:** polling connects again when the Telegram ingress worker runs from a source checkout or a packaged plugin build. (#154286, #154180) Thanks @xydt-juyaohui and @markfietje.
- **Control UI:** an open chat recovers after a Gateway update instead of sticking on **Server updated → Retry now**, keeping its original deep link. (#168941)
- **Updates and recovery:** managed updates settle eligible stale package recovery after a lost or replaced handoff lease database and archive completed receipts before the next preparation; `--dry-run` only reports the planned settlement. (#169038, #167506, #167771) Thanks @mkdelta221 and @waynegault.
- **Legacy update records:** 2026.9.8 package recovery records settle by identity and version after metadata drift, completed-receipt identity drift no longer blocks updates, and public repair exits nonzero with guidance when a journal stays pending. (#169027, #168856, #168388, #168092) Thanks @chedong and @k94118.
- **Update memory and webhooks:** update children inherit the managed service's heap limits so Doctor finishes on large agent databases, and official webhook plugins deferred during candidate Doctor keep their listeners, including Teams' historical port 3978. (#168889, #168729, #169035, #168872) Thanks @bluet and @sirius1024.
- **Windows updates:** updater workers stay on the retained runtime, and `openclaw doctor --fix` reclaims retained runtimes, when the install path uses a Windows short (8.3) name or a differently cased spelling. (#169292) Thanks @RomneyDa.
- **Doctor maintenance:** Doctor and update repair enter maintenance on a running systemd Gateway even when checking a large state database is slow. (#168161, #168031) Thanks @obviyus and @Tosko4.

## 2026.10.6


### v2026.10.6

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.10.6).

**Security release:** v2026.10.6 adds remediations for the eMudhra certificate compromise. If you manage Node yourself, upgrade to Node 24.22.1 or newer (Node 24) or 26.12.1 or newer (Node 26) before starting OpenClaw.

This is a patch release with no new features. It contains urgent fixes for problems that could stop OpenClaw from installing, updating, or starting, plus smaller reliability fixes.

**Release scale:** 233 pull requests, 30 direct commits, and 149 contributors.

#### Security and Privacy

- Adds remediations for the eMudhra certificate compromise. OpenClaw now requires Node 24.22.1 or newer on Node 24, or 26.12.1 or newer on Node 26, because older Node builds may still trust the affected certificates. If you manage Node yourself, upgrade before starting OpenClaw. Docker images and installers already use the patched versions.
  Source builds use pnpm 12.15.0. [#179992](https://github.com/openclaw/openclaw/pull/179992). Thanks to [@joshavant](https://github.com/joshavant).

  This prevents inappropriate legacy-data migration and warnings for the wrong profile. Preserve the original directory. [#171439](https://github.com/openclaw/openclaw/pull/171439).

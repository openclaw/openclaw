## 2026.11.2


### v2026.11.2

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.2).

This is a patch release with no new features. It fixes problems that could stop updates, leave scheduled reminders missing, or cause chat widgets to appear twice, alongside smaller reliability fixes.

This release draws on 113 pull requests and 30 direct commits, with contributions from 64 GitHub accounts.

#### Installation and Onboarding

- Fixes global installation with Bun 1.4.4 when Node is not installed.
  [#175990](https://github.com/openclaw/openclaw/pull/175990). Thanks to [@steipete](https://github.com/steipete). See the [installation guide](https://docs.openclaw.ai/install/).
- Prevents Hermes migration from silently changing settings or credentials when source files contain malformed UTF-8. Re-encode the named file and retry.
  [#180264](https://github.com/openclaw/openclaw/pull/180264). Thanks to [@steipete](https://github.com/steipete), [@Leon-SK668](https://github.com/Leon-SK668) and [@wangmiao0668000666](https://github.com/wangmiao0668000666).
- Fixes Windows configure refusals and false Doctor warnings when Gateway paths differ only in letter case.
  [#185917](https://github.com/openclaw/openclaw/pull/185917), [#185913](https://github.com/openclaw/openclaw/issues/185913). Thanks to [@YangManBOBO](https://github.com/YangManBOBO) and [@steipete](https://github.com/steipete).
- Fixes browser extension setup rejecting group-writable package files created by the shell installers on systems with permissive file permissions. Existing installations need an installer-driven upgrade or reinstall.
  [#186782](https://github.com/openclaw/openclaw/pull/186782), [#179493](https://github.com/openclaw/openclaw/issues/179493). Thanks to [@javiermv](https://github.com/javiermv).

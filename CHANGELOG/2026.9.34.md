## 2026.9.34

### Highlights

- **Safer agent file edits:** `apply_patch` now validates an ordered envelope before mutating the workspace, so a later invalid hunk cannot delete files changed by an earlier operation. (#160409) Thanks @masatohoshino, @obviyus, and @RomneyDa.
- **More reliable managed upgrades:** app-owned updates now converge official plugins alongside core and retain repair diagnostics. Fixes #174120. (#174257) Thanks @kazuyuki-eguchi and @RomneyDa.
- **Memory Wiki data safety:** OKF concept re-imports now preserve human-authored notes. Fixes #175700. (#175707) Thanks @YangManBOBO and @RomneyDa.
- **Reliable model startup and selection:** Gateway startup now survives model-refresh ownership replacement, and catalog readiness honors the effective primary model's configured account pin. Fixes #178502. (#173366, #178522) Thanks @ericcaiwx-star, @eduardonunesfreire-rgb, and @RomneyDa.
- **Gateway and integration stability:** log rotation no longer spins on a deleted `/tmp`, Buzz relay closure no longer exits the Gateway during authentication, and OpenRouter onboarding accepts valid credentials. Fixes #147269. (#160433, #170591, #173292) Thanks @masatohoshino, @jarvis-modern-mail, @chandraveshchaudhari, @RomneyDa, and @WadeOwenWatts.
- **Plugin hooks restored:** `before_tool_call` hooks now run under `openclaw agent exec`. Fixes #158824. (#159333) Thanks @joseairosa and @RomneyDa.

### Changes

- **Managed update convergence:** official plugins are reconciled to the app-managed core version during upgrades, with diagnostics retained for repair paths. Fixes #174120. (#174257) Thanks @kazuyuki-eguchi and @RomneyDa.

### Fixes

- **Agent patch atomicity:** preflight ordered `apply_patch` envelopes before mutation so later invalid hunks cannot destroy earlier files. (#160409) Thanks @masatohoshino, @obviyus, and @RomneyDa.
- **Memory Wiki note preservation:** retain human-authored notes when OKF concepts are imported again. Fixes #175700. (#175707) Thanks @YangManBOBO and @RomneyDa.
- **Model lifecycle and auth selection:** keep startup alive through model-refresh replacement and honor the configured primary account pin during catalog readiness. Fixes #178502. (#173366, #178522) Thanks @ericcaiwx-star, @eduardonunesfreire-rgb, and @RomneyDa.
- **Gateway logging and Buzz stability:** avoid deleted-log-target CPU spin and prevent NIP-42 relay closure from exiting the Gateway. Fixes #147269. (#160433, #170591) Thanks @masatohoshino, @jarvis-modern-mail, @RomneyDa, and @WadeOwenWatts.
- **OpenRouter onboarding:** accept valid API keys during route verification. (#173292) Thanks @chandraveshchaudhari and @RomneyDa.
- **Agent plugin hooks:** restore `before_tool_call` execution for `openclaw agent exec`. Fixes #158824. (#159333) Thanks @joseairosa and @RomneyDa.
- **Cross-release updater compatibility:** retain the 2026.10.1 launchd observation and updater runtime exports during extended-stable replacement, and conservatively refuse immutable-install mutation on this older release line. (#160663) Thanks @RomneyDa.
- **Release validation compatibility:** reconcile branch-native update admission, declaration surfaces, safety baselines, and test fixtures required by the current full-release validation toolchain. (#180988) Thanks @RomneyDa.

## 2026.11.3


### v2026.11.3

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.3).

**Security release:** This release fixes certificate verification for worker transfers with blank fingerprints, keeps required-sandbox image previews within allowed folders and reduces credential exposure. Update OpenClaw to receive these fixes.

This is a patch release with no new features. It fixes problems that could leave the Gateway stopped after an update, block backups on slow storage, or expose private information, alongside smaller reliability fixes.

**Release scale:** 56 pull requests, 44 direct commits, and 36 contributors. The pull request count includes backported source work, while direct commits count separately retained release-line changes.

#### Updates and Maintenance

- Fixes a running Windows Gateway losing its lock when system boot information disagrees. On Linux, fixes startup failing to recover a stale lock when its old process ID has been reused by a worker thread.
  [#175118](https://github.com/openclaw/openclaw/pull/175118). Thanks to [@xiaopan-xydt](https://github.com/xiaopan-xydt), [@steipete](https://github.com/steipete), [@belbix](https://github.com/belbix).
- Fixes nonnative package updates stopping at an initial presence-check timeout when the existing installation identity can still be captured. If an update from 2026.9.3 or 2026.9.4 is blocked by this timeout, follow the [update recovery guidance](https://docs.openclaw.ai/install/updating). Selecting a newer version does not fix the installed updater.
  [Released change](https://github.com/openclaw/openclaw/commit/819f3177d2093b0131a0e5750c7581cec797ee6a), adapting [#181906](https://github.com/openclaw/openclaw/pull/181906). Thanks to [@steipete](https://github.com/steipete), [@node-sketch](https://github.com/node-sketch) and [@RomneyDa](https://github.com/RomneyDa).
- Fixes a managed macOS Gateway restarting during update maintenance when its LaunchAgent background service remains loaded. Stopping the service no longer by itself causes SQLite migration to reject the captured database as changed.
  [#187104](https://github.com/openclaw/openclaw/pull/187104). Thanks to [@RomneyDa](https://github.com/RomneyDa), [@steipete](https://github.com/steipete).
- Fixes large backups timing out because all files shared one SQLite discovery deadline.
  [#187197](https://github.com/openclaw/openclaw/pull/187197). Thanks to [@wr-web](https://github.com/wr-web), [@obviyus](https://github.com/obviyus), [@etzelm](https://github.com/etzelm).
- Fixes some interrupted package updates reporting success instead of preserving cancellation and the recovery path.
  [#187998](https://github.com/openclaw/openclaw/pull/187998). Thanks to [@vincentkoc](https://github.com/vincentkoc).
- Fixes interrupted managed updates and repairs leaving the Gateway stopped when recovery checks permit a restart. If completed maintenance cannot start or verify the Gateway, repair gives manual start and status guidance. A recovered Gateway does not itself mean the update completed. See [update recovery](https://docs.openclaw.ai/install/updating).
  [#193884](https://github.com/openclaw/openclaw/pull/193884). Thanks to [@steipete](https://github.com/steipete), [@RomneyDa](https://github.com/RomneyDa).
- Fixes misleading backup discovery errors when a SQLite check times out and points affected operators to [recovery guidance](https://docs.openclaw.ai/install/updating).
  [#193970](https://github.com/openclaw/openclaw/pull/193970). Thanks to [@steipete](https://github.com/steipete) and [@karam2022](https://github.com/karam2022).
- Fixes backups and update discovery failing on slow storage when a large SQLite check times out by retrying smaller batches. A file that still times out on its own continues to block the backup. If an update from 2026.10.10 or 2026.11.1 is blocked by this timeout, follow the [update recovery guidance](https://docs.openclaw.ai/install/updating). The installed updater cannot acquire this fix by selecting a newer version.
  [#194239](https://github.com/openclaw/openclaw/pull/194239). Thanks to [@steipete](https://github.com/steipete).
- Fixes resumed chat-initiated updates failing an authorization check for an otherwise authorized profile before plugin work. Revoked requesters remain blocked.
  [Released change](https://github.com/openclaw/openclaw/commit/60163555e546c76078922c722d6a75f22f2917b6), adapting [#177792](https://github.com/openclaw/openclaw/pull/177792). Thanks to [@GrahamMcBain](https://github.com/GrahamMcBain), [@steipete](https://github.com/steipete).
- Fixes update repair being blocked by database changes before or during the Doctor handoff. Doctor cannot automatically restore the database when it cannot verify who made those writes.
  [Released change](https://github.com/openclaw/openclaw/commit/fdce260c88ef167024fdd5b993e8762d568ac816). Thanks to [@RomneyDa](https://github.com/RomneyDa).
- Reduces the memory pressure that could cause large session transcript search index repairs to run out of memory.
  [Released change](https://github.com/openclaw/openclaw/commit/6de33ec716be6c78c004dfebbfce571918e632d1), adapting [#194099](https://github.com/openclaw/openclaw/pull/194099). Thanks to [@vincentkoc](https://github.com/vincentkoc).

#### Security and Privacy

- Fixes blank node TLS fingerprint flags suppressing the saved certificate pin for the same Gateway endpoint.
  [#125646](https://github.com/openclaw/openclaw/pull/125646). Thanks to [@wanyongstar](https://github.com/wanyongstar), [@steipete](https://github.com/steipete).
- Prevents a known [Twitch](https://docs.openclaw.ai/channels/twitch) IRC parsing error from copying incoming message content into error logs while retaining a parsing-failure notice.
  [#174552](https://github.com/openclaw/openclaw/pull/174552). Thanks to [@steipete](https://github.com/steipete).
- Fixes conversation image previews reading outside allowed folders in required-sandbox sessions, including in Full Access mode. An administrator can still allow a specific outside image.
  [#176203](https://github.com/openclaw/openclaw/pull/176203). Thanks to [@shakkernerd](https://github.com/shakkernerd).
- Limits the environment inherited by managed Signal daemons to reduce exposure of unrelated credentials. Proxy, trust-store and custom wrapper variables are no longer inherited and may need to be supplied through Java properties, the wrapper or an external daemon. See the [Signal guide](https://docs.openclaw.ai/channels/signal).
  [#179198](https://github.com/openclaw/openclaw/pull/179198). Thanks to [@VACInc](https://github.com/VACInc).
- Requires normal authorization for dynamic shell `test` and `[` predicates under the Gateway allowlist, closing an automatic-approval gap. Some quoted literal filenames containing metacharacters also require authorization and may be denied when approvals are off. The command renderer also catches unquoted globs after escaped ANSI-C quotes or PID-prefixed quote sequences. See [exec approvals](https://docs.openclaw.ai/tools/exec).
  [#187884](https://github.com/openclaw/openclaw/pull/187884). Thanks to [@art22s](https://github.com/art22s).
- Fixes blank worker transfer TLS fingerprints disabling certificate verification for workspace uploads and downloads. Blank pins use normal CA verification, while malformed nonblank HTTPS pins are rejected.
  [#190002](https://github.com/openclaw/openclaw/pull/190002). Thanks to [@avelev99](https://github.com/avelev99) and [@aniruddhaadak80](https://github.com/aniruddhaadak80).
- Fixes config reads exposing inline values in `env.vars` and suppresses raw config output when it cannot be safely redacted.
  [Released change](https://github.com/openclaw/openclaw/commit/3d2198d8d336ced87008cd4b4cca581b552a52f3), adapting [#190618](https://github.com/openclaw/openclaw/pull/190618). Thanks to [@yetval](https://github.com/yetval).
- Fixes private completion text reaching session-message subscribers and private activity appearing in the Control UI during session preparation.
  [Released change](https://github.com/openclaw/openclaw/commit/9fde2f36f855f40d4748e2338ee0efc509304313), adapting [#188490](https://github.com/openclaw/openclaw/pull/188490). Thanks to [@fuller-stack-dev](https://github.com/fuller-stack-dev).
- Prevents another provider plugin from redirecting a provider connection to a different origin or supplying a destination when none was set, reducing the risk of sending credentials to the wrong endpoint.
  [Released change](https://github.com/openclaw/openclaw/commit/b578781366be2a5ddd5f83a145a4bc5bf282e46b), adapting [#189423](https://github.com/openclaw/openclaw/pull/189423). Thanks to [@obviyus](https://github.com/obviyus).

Servers that relied on other inherited settings may need an allowed entry in their bundle configuration or a wrapper. See [plugin bundle guidance](https://docs.openclaw.ai/plugins/bundles).
  [Released change](https://github.com/openclaw/openclaw/commit/a8a1875176d1f12f10dae0ce6e37d391f355ede3), adapting [#179415](https://github.com/openclaw/openclaw/pull/179415). Thanks to [@VACInc](https://github.com/VACInc).
- Fixes Firecrawl search and scrape mixing credentials with another connection’s endpoint. Configurations that depended on mixing scoped values may need adjustment.
  [Released change](https://github.com/openclaw/openclaw/commit/52c0ce28af5697085d228b9bae41f1599db5fd84), adapting [#190706](https://github.com/openclaw/openclaw/pull/190706). Thanks to [@zhangguiping-xydt](https://github.com/zhangguiping-xydt).

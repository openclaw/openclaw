## 2026.11.6


### OpenClaw v2026.11.6

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.6).

OpenClaw 2026.11.6 is a patch release with bug fixes and quality-of-life improvements throughout OpenClaw, from installation and updates to messaging, model providers, plugins and the native apps.

**Release scale:** 386 pull requests, 48 direct commits, and 157 contributors.

#### Installation and Onboarding

- Fixes missing-file errors in new shells after uninstalling OpenClaw state by removing matching stale completion registrations. [#186080](https://github.com/openclaw/openclaw/pull/186080), [#112625](https://github.com/openclaw/openclaw/issues/112625). Thanks [@MoerAI](https://github.com/MoerAI), [@obviyus](https://github.com/obviyus), and [@kangarooo](https://github.com/kangarooo).
- Fixes state cleanup removing a workspace selected for preservation when its path uses a directory alias. Reinstalling a plugin through an alias also no longer removes the newly installed copy as an old replacement. [29b9961](https://github.com/openclaw/openclaw/commit/29b996197c3aa5cb219efa94eaa03522c8aec13a). Thanks [@obviyus](https://github.com/obviyus) and [@RomneyDa](https://github.com/RomneyDa).
- Fixes fresh macOS and Linux installs silently choosing stable when you requested beta and npm was not yet installed. If beta cannot be found after setup, the installer warns before falling back to latest. Windows PowerShell installs also recheck the selected package's Node requirement after provisioning. [#188005](https://github.com/openclaw/openclaw/pull/188005), [issue #187982](https://github.com/openclaw/openclaw/issues/187982). Thanks [@steipete](https://github.com/steipete) and [@mcgatom](https://github.com/mcgatom), who reported the issue.
- Fixes the Linux installer continuing after it fails to set up a user-local npm prefix. It now stops with an error before changing shell profiles or installing the package. [#188292](https://github.com/openclaw/openclaw/pull/188292). Thanks [@McgAtom](https://github.com/McgAtom) and [@steipete](https://github.com/steipete).
- Fixes private npm and Git installations failing their version check or producing unusable launchers when their paths contain shell characters. Quote paths passed to --prefix or --git-dir, and rerun the installer to regenerate an existing launcher. [#189541](https://github.com/openclaw/openclaw/pull/189541). Thanks [@mcgatom](https://github.com/mcgatom) and [@obviyus](https://github.com/obviyus).
- Fixes workspace preparation deleting custom onboarding instructions before they are used when a workspace already has profiles or skills. [#196411](https://github.com/openclaw/openclaw/pull/196411). Thanks [@Patrick-Erichsen](https://github.com/Patrick-Erichsen).
- Fixes local non-interactive onboarding leaving legacy credentials unavailable after you configure authentication. It imports existing profiles first and archives the original files. [Commit 6e17e50](https://github.com/openclaw/openclaw/commit/6e17e5011b35c79ad2ee989c250dfd8d60697418). Thanks [@RomneyDa](https://github.com/RomneyDa).
- Fixes onboarding memory imports failing when a compatible Gateway is already running. A configured onboarding rerun also connects its hatch to that Gateway. Full migration discovery still requires the Gateway to be stopped. [Commit d7e9ff0](https://github.com/openclaw/openclaw/commit/d7e9ff00e8d29ac1d5db0268fd6e96762068c39e). Thanks [@sallyom](https://github.com/sallyom) and [@RomneyDa](https://github.com/RomneyDa).
- Fixes first-time systemd unit installation being refused when local drop-in files already exist. Existing drop-ins remain untouched. [67c6124](https://github.com/openclaw/openclaw/commit/67c6124b0fc7886fbdbc7665ff211cc6b8ed4767). Thanks [@holgergruenhagen](https://github.com/holgergruenhagen), [@sallyom](https://github.com/sallyom), and [@RomneyDa](https://github.com/RomneyDa).

## 2026.11.7


### OpenClaw v2026.11.7

For formatted release notes, [read this release on the docs site](https://docs.openclaw.ai/releases/2026.11.7).

OpenClaw 2026.11.7 is a patch release focused on reliability across setup, updates, conversations, and automations. It also improves the apps, models, and integrations you use with OpenClaw.

**Release scale:** 533 pull requests, 175 direct commits, and 214 contributors.

# v2026.10.4

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.10.4.md).

OpenClaw v2026.10.4 fixes update and recovery problems, including interrupted work after sleep or clock changes and chats stuck after an update, alongside repairs for messaging, model tools and sign-in.

**Release scale:** 55 pull requests, 24 direct commits, and 49 contributors.

## Web UI

- **Chat refresh after updates.** Chats stuck on “Server updated” can refresh back to the same conversation link. If your tab was open before updating, save unsaved work and reload it once to load this fix.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#168941](https://github.com/openclaw/openclaw/pull/168941), thanks to [@steipete](https://github.com/steipete).

  </details>

- **Dashboard connection.** Open dashboards can stay connected when a busy Gateway delays its check-in messages, avoiding unnecessary reconnects. Requests still have their own timeouts.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#171253](https://github.com/openclaw/openclaw/pull/171253), thanks to [@steipete](https://github.com/steipete).

  </details>

## Updates and Maintenance

- **Sleep and clock changes.** Fixed unnecessary interruptions after computer sleep or backward clock changes, with clearer [restart guidance](/gateway/restart-recovery) when OpenClaw loses access to its saved state.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#170790](https://github.com/openclaw/openclaw/pull/170790), thanks to [@steipete](https://github.com/steipete), [@jjjhenriksen](https://github.com/jjjhenriksen), [@AnvinaLI](https://github.com/AnvinaLI), [@sgh6688](https://github.com/sgh6688), [@waynegault](https://github.com/waynegault), [@andersgreg](https://github.com/andersgreg) and [@shawnholt](https://github.com/shawnholt).

  </details>

- **Gateway shutdown.** Stopping or restarting OpenClaw no longer hangs on stalled conversation indexing, and pending session updates can finish before connected clients close. Saved transcripts remain available after a [restart](/gateway/restart-recovery).

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#170493](https://github.com/openclaw/openclaw/pull/170493), [#170555](https://github.com/openclaw/openclaw/pull/170555), thanks to [@steipete](https://github.com/steipete), [@Oldrich333](https://github.com/Oldrich333) and [@O96a](https://github.com/O96a).

  </details>

- **Old login files.** Unused retired OAuth files no longer block Doctor, updates or Docker startup, and remain preserved. Referenced files still need the documented [2026.9.7 recovery on the original host](/gateway/doctor/config-migrations#retention-policy).

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#165420](https://github.com/openclaw/openclaw/pull/165420), thanks to [@obviyus](https://github.com/obviyus).

  </details>

- **Update snapshots.** After installing 10.4, later upgrades avoid false warnings that an unchanged database changed while its recovery copy was made. Real later changes can still prevent [automatic restoration](/install/updating/rollback-and-recovery).

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#170351](https://github.com/openclaw/openclaw/pull/170351), thanks to [@DonnieFi](https://github.com/DonnieFi) and [@RomneyDa](https://github.com/RomneyDa).

  </details>

- **Updates after data migration.** Update checks avoid false verification failures after data migration. Status also stops repeating a saved restart warning once the running Gateway reports the expected version. See [rollback and recovery](/install/updating/rollback-and-recovery).

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#170130](https://github.com/openclaw/openclaw/pull/170130), thanks to [@steipete](https://github.com/steipete) and [@angeliti999](https://github.com/angeliti999).

  </details>

- **Temporary update files.** Doctor and updates can remove abandoned temporary update directories despite unrelated system processes, including ordinary Linux systemd user sessions. Directories still used by live OpenClaw processes remain protected.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#166335](https://github.com/openclaw/openclaw/pull/166335), [#171488](https://github.com/openclaw/openclaw/pull/171488), thanks to [@vincentkoc](https://github.com/vincentkoc), [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).

  </details>

- **Temporary disk use.** Update checks reuse eligible prepared database copies instead of duplicating them again, and give clearer retry guidance for space failures.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#167451](https://github.com/openclaw/openclaw/pull/167451), thanks to [@steipete](https://github.com/steipete), [@iFadi](https://github.com/iFadi), [@dankarization](https://github.com/dankarization), [@azuretek](https://github.com/azuretek) and [@davidcittadini](https://github.com/davidcittadini).

  </details>

- **Update progress.** Temporary congestion while printing progress no longer aborts update inspection, and terminal progress waits through Doctor maintenance before resuming.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#168493](https://github.com/openclaw/openclaw/pull/168493), [#171454](https://github.com/openclaw/openclaw/pull/171454), thanks to [@vincentkoc](https://github.com/vincentkoc), [@creanet-64](https://github.com/creanet-64), [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).

  </details>

- **Update failure guidance.** Snapshot-preparation failures now point to the snapshot step that failed, instead of runtime verification that never ran.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#171457](https://github.com/openclaw/openclaw/pull/171457), thanks to [@RomneyDa](https://github.com/RomneyDa) and [@DonnieFi](https://github.com/DonnieFi).

- **Maintenance warnings.** Completed plugin upgrades stop leaving stale “unfinished” warnings in [update history](/cli/update/status-and-history). Expected database maintenance also stops producing false checkpoint-failure warnings.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

- **Scheduled work during updates.** After installing 10.4, later update checks give scheduled jobs and cleanup a chance to save while the updater waits to record its progress.

- **Schedule inspection during recovery.** Updates and Doctor can continue when optional memory dreaming schedule checks fail, preserving scheduled jobs. Retry pending dreaming repairs with `openclaw doctor --fix`. Successful job-list reads also survive temporary snapshot cleanup failures.

  <details class="release-source-toggle release-source-inline">

## Security and Privacy

- **Tlon group-DM permissions.** Unverified group-DM author claims no longer gain owner commands, approval/admin actions or elevated tool permissions. A group member can still pose as an allowed sender to chat with the agent, and replies go to the impersonated sender's private conversation. After approving a pending DM saved before updating, [ask the sender to resend it](/channels/tlon).

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#165801](https://github.com/openclaw/openclaw/pull/165801), thanks to [@eleqtrizit](https://github.com/eleqtrizit).

  </details>

## Other Bug Fixes

- **Node worker memory limits.** Node workers can honor their configured JavaScript heap limits when OpenClaw starts with a larger heap setting, while the main process keeps its own heap size.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [b77060f](https://github.com/openclaw/openclaw/commit/b77060fc6c248f0dd3fed9c7d3903b73117da6d2), thanks to [@xydigitLybnnnn](https://github.com/xydigitLybnnnn).

  </details>

- **Streamed code examples.** Long streamed answers that quote XML tool instructions in a code block avoid repeated processing that could delay delivery. The example stays visible, while actual leaked tool instructions are still filtered out.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#171573](https://github.com/openclaw/openclaw/pull/171573), thanks to [@steipete](https://github.com/steipete) and [@boeingchoco](https://github.com/boeingchoco).

  </details>

- **Repeated historical warnings.** Later runs of a conversation stop repeating warnings for work already marked as blocked, making old failures less likely to look new. The blocked work is not repaired, and its records remain.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

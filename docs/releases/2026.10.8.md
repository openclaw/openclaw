# v2026.10.8

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.10.8.md).

**Security release:** v2026.10.8 adds remediations for the eMudhra certificate compromise in the secret egress proxy and its exported trust bundle. Restart the Gateway to apply the change. Apps with independent trust stores and bypass tunnels need their own updates.

This is a patch release with no new features. It fixes problems that could stop OpenClaw from installing, updating, starting or delivering replies, alongside smaller app, channel and provider fixes.

# OpenClaw v2026.11.9

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.9.md).

OpenClaw 2026.11.9 is a focused patch release improving prompt caching on forked sessions, Tool Search compatibility, Claude CLI and ACP reply delivery, headed Chrome screenshots, and security guards.

**Release scale:** 10 pull requests, 3 direct commits, and 5 contributors.

## Models and Providers

- Updates the bundled Codex app-server to version 0.172.0 and refreshes its app-server protocol bindings.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [48a3272](https://github.com/openclaw/openclaw/commit/48a327268c8094a6482f3d9719f8326ee22a0d93).

  Thanks [@RomneyDa](https://github.com/RomneyDa).

  </details>

- Stops Anthropic session forks such as Advisor reviews and /btw requests from writing prompt cache checkpoints on their own one-off suffix, while still reading the parent conversation's cached prefix.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#197224](https://github.com/openclaw/openclaw/pull/197224).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

- Fixes OpenAI Responses session forks such as Advisor reviews and /btw requests failing to reuse the parent conversation's prompt cache, aligning cache keys, hosted tools, and reasoning settings so forks avoid reprocessing the full prompt.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#197226](https://github.com/openclaw/openclaw/pull/197226).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

- Fixes signing in to a provider again while the Gateway is running overwriting configured model rows and explicit thinking-level entries in openclaw.json. Re-authentication now saves credentials without modifying existing model definitions.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#201742](https://github.com/openclaw/openclaw/pull/201742).

  Thanks [@MertBasar0](https://github.com/MertBasar0).

  </details>

- Fixes turns that call web_search or other Tool Search directory tools failing on OpenAI-compatible chat-completions providers that reject assistant message prefill. Callable directory tools now stay in native tool-call history instead of replaying as assistant text.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#202436](https://github.com/openclaw/openclaw/pull/202436).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

- Fixes background Claude CLI runs failing with an unavailable secret file descriptor error when using an OpenClaw-stored subscription token on foreground Gateways, containers, or Windows. Secret input now stays available until the prompt finishes sending.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#202646](https://github.com/openclaw/openclaw/pull/202646).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

## Browser and Computer Use

- Fixes browser tool screenshots of background tabs timing out and blocking later captures in headed Chrome on managed and attach-only profiles. Background tabs now render for capture without switching away from your active tab or window.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#202878](https://github.com/openclaw/openclaw/pull/202878).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

## Plugins and Integrations

- Fixes ACP clients receiving truncated replies when a prompt is queued behind other work on the same session. The ACP bridge now recovers and streams any remaining committed reply text before ending the turn.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#202658](https://github.com/openclaw/openclaw/pull/202658).

  Thanks [@obviyus](https://github.com/obviyus).

  </details>

## Security and Privacy

- Keeps requests to self-hosted web tool endpoints on their configured hostname across every redirect hop, rejecting redirects to other hosts while keeping configured private endpoints and same-host redirects working. If a self-hosted endpoint redirects to a different hostname, configure that destination hostname directly.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196847](https://github.com/openclaw/openclaw/pull/196847).

  Thanks [@drobison00](https://github.com/drobison00).

  </details>

- Fixes Discord direct-message senders who were removed from the allowlist or unpaired still being able to message the agent and run commands through an earlier session binding. Removed senders now hit the normal denial or pairing flow while admitted senders keep their existing bindings.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196848](https://github.com/openclaw/openclaw/pull/196848).

  Thanks [@drobison00](https://github.com/drobison00).

  </details>

- Fixes command execution checks missing shell startup variables such as BASH_ENV and ENV when passed inside env -S or nested env --split-string commands. Those assignments are now rejected consistently while ordinary environment assignments continue working.
  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#203934](https://github.com/openclaw/openclaw/pull/203934).

  Thanks [@pgondhi987](https://github.com/pgondhi987).

  </details>

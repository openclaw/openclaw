# v2026.11.5

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.5.md).

OpenClaw 2026.11.5 release notes document 138 bug-fix entries and 18 quality-of-life entries.

## Quality of life

### Chat and sessions

- Adds a keyboard link to skip the chat transcript and reach the message composer. In archived chats it leads to the footer and Unarchive.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#180896](https://github.com/openclaw/openclaw/pull/180896). Thanks to [@goutamadwant](https://github.com/goutamadwant), [@liuwqgit](https://github.com/liuwqgit), [@obviyus](https://github.com/obviyus) and [@carlopignatari-boop](https://github.com/carlopignatari-boop).

  </details>

- Simplifies paired-device folder selection in New Session. Admins can browse, other writers can enter an absolute path, and the selected folder name appears in the workspace chip. The menu also explains when the selected model cannot use device folders.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#190088](https://github.com/openclaw/openclaw/pull/190088). Thanks to [@obviyus](https://github.com/obviyus) and [@RomneyDa](https://github.com/RomneyDa).

  </details>

- Adds global and per-agent [limits for client-side compaction summaries](/concepts/compaction#summary-size). The default remains 16,000 characters; larger summaries use more context and cost more to replay.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196207](https://github.com/openclaw/openclaw/pull/196207). Thanks to [@aniruddhaadak80](https://github.com/aniruddhaadak80), [@garrytan](https://github.com/garrytan), [@RomneyDa](https://github.com/RomneyDa) and [@vincentkoc](https://github.com/vincentkoc).

  </details>

- Reduces JavaScript loaded when opening Chat by deferring the Template creator and workspace conflict recovery controls until needed.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#187783](https://github.com/openclaw/openclaw/pull/187783), [#187830](https://github.com/openclaw/openclaw/pull/187830). Thanks to [@vincentkoc](https://github.com/vincentkoc).

  </details>

- Clarifies the error for oversized compressed conversation archives, suggesting uncompressed JSONL as an alternative.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [commit 2b08b6f](https://github.com/openclaw/openclaw/commit/2b08b6f7880ded69c626f5c63f087517c0802bcd). Thanks to [@RomneyDa](https://github.com/RomneyDa).

  </details>

- Extends existing widgets to compatible private Telegram bot chats, including private topics. [Telegram message widgets](/channels/telegram/rich-messages) are opt-in and off by default; older Telegram clients cannot render them.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196991](https://github.com/openclaw/openclaw/pull/196991), [#198022](https://github.com/openclaw/openclaw/pull/198022). Thanks to [@obviyus](https://github.com/obviyus) for the widget transport and private-topic work, and [@dankarization](https://github.com/dankarization) for private-topic routing.

  </details>

### Tools and providers

- Adds a [directory of eligible deferred MCP tools](/tools/tool-search#mcp-tool-directory) to Tool Search, so agents can discover listed tools without a separate search. Large catalogs may still require a search for omitted names.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196252](https://github.com/openclaw/openclaw/pull/196252). Thanks to [@jalehman](https://github.com/jalehman), [@GrahamMcBain](https://github.com/GrahamMcBain) and [@RomneyDa](https://github.com/RomneyDa).

  </details>

- Adds compact [input signatures](/tools/tool-search#search) to MCP Tool Search results, helping agents make straightforward calls without requesting every full tool description. Complex or missing schemas may still need the full description.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [#196266](https://github.com/openclaw/openclaw/pull/196266). Thanks to [@jalehman](https://github.com/jalehman), [@GrahamMcBain](https://github.com/GrahamMcBain) and [@RomneyDa](https://github.com/RomneyDa).

  </details>

- Adds [Gemini Decision 1](/providers/google#decision-models) as a provider option for Boolean, choice and score evaluations of text, JSON or one supported image. It requires a Gemini Developer API key; evaluation sends evidence to Google and incurs API charges. This is not a chat or Vertex model.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

  [commit 01b98da](https://github.com/openclaw/openclaw/commit/01b98da7d3dbcca5d26a6a970f1ab0438adfdcab). Thanks to [@RomneyDa](https://github.com/RomneyDa), [@vincentkoc](https://github.com/vincentkoc) and [@obviyus](https://github.com/obviyus).

  </details>

- Adds a read-only GitHub publication readiness check so agents can inspect a session’s source and existing publication requests without starting a publication.

  <details class="release-source-toggle release-source-inline">
  <summary>More details</summary>

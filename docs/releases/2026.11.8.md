# OpenClaw v2026.11.8

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.8.md).

OpenClaw 2026.11.8 is a patch release focused on reliability across chats, updates, models, and automations. It also cleans up issues in the apps, plugins, and Web UI.

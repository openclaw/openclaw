# v2026.11.1

AI agents and tools can read these release notes as [plain Markdown](https://raw.githubusercontent.com/openclaw/openclaw/main/CHANGELOG/2026.11.1.md).

This patch release has no new features. It improves managed Gateway service start messages and fixes problems that could interrupt Telegram and Discord conversations.

**Release scale:** 21 pull requests, 0 direct commits, and 4 contributors.

The pull request count includes backported source work.

## Updates and Maintenance

- When starting the managed [Gateway](/cli/gateway) service, readiness messages now show more specific status, such as when the service stays stopped or the health check times out.

  <summary>More details</summary>

  See the [release backport](https://github.com/openclaw/openclaw/pull/190034). Thanks to [@RomneyDa](https://github.com/RomneyDa).

  </details>

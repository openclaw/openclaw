# OpenClaw Keenable Plugin

Official OpenClaw plugin for [Keenable](https://keenable.ai/) web search. Requires a
free API key; each Keenable org gets [100k free requests per month](https://keenable.ai/pricing).

Install from OpenClaw:

```bash
openclaw plugins install @openclaw/keenable-plugin
openclaw gateway restart
```

See <https://docs.openclaw.ai/tools/keenable-search> for setup and configuration.

Keenable’s integration page: <https://docs.keenable.ai/integrations/openclaw>.

# Slack huddles

Join an active Slack huddle through a dedicated Slack user signed into the OpenClaw Chrome profile. This plugin is disabled by default.

```bash
openclaw plugins install @openclaw/slack-huddles
openclaw plugins enable slack-huddles
```

See https://docs.openclaw.ai/plugins/slack-huddles for setup, modes, audio routing, captions, and limitations.

- Plugin id: `slack-huddles`
- Tool: `slack_huddles`
- CLI: `slackhuddles`
- Package: `@openclaw/slack-huddles`
- Minimum OpenClaw host: `2026.7.2`

# OpenClaw Cloudflare Clef

Unpublished source-checkout Decision plugin for Clef, Clef Flash, and Clef Omni
through the Gateway user's existing `cf` CLI login. It needs a source host with
the prepared V2 Decision API.

```bash
openclaw plugins install --link ./extensions/cloudflare-clef
```

See <https://docs.openclaw.ai/plugins/cloudflare-clef> for host compatibility,
setup, limits, and live verification.

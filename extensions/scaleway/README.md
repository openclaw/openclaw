# OpenClaw Scaleway Provider

Official OpenClaw provider plugin for Scaleway Generative APIs models through an
OpenAI-compatible API hosted in the EU.

Install from OpenClaw:

```bash
openclaw plugins install @openclaw/scaleway-provider
openclaw gateway restart
```

Configure a Scaleway API key (`SCW_SECRET_KEY`), then select models with refs
such as `scaleway/glm-5.3`.

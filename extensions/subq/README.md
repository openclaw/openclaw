# SubQ Snap

External OpenClaw decision-provider plugin for SubQ Snap typed decisions. SubQ retired `subq-snap-preview` on 2026-11-11; see docs/plugins/subq.md.
Uses the typed Decisions API, not chat completions. Disabled by default.

See [setup, supported input, and limitations](https://docs.openclaw.ai/plugins/subq).
Package publication is pending; use a source checkout containing this plugin.

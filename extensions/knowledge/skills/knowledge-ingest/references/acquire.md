# Acquire by source format

Recorder-, format- and site-specific handling ends here; every source runs the
same steps after it.

- **Articles and web content:** use available host fetch tools; extract title,
  author, publication, date and full available text. Summarize executive
  takeaways and key arguments, not a rehash. Explain what is interesting given
  existing Knowledge; flag connections and contradictions as analysis, not
  source facts.
- **PDFs and documents:** use available host extraction or OCR; summarize
  executive takeaways, key sections and notable data. Keep the original and
  extracted text separately identified.
- **Audio, video and images:** use authorized host transcription or OCR when
  available. Retain transcripts (including diarization and timing when
  supplied) and link them from the page. Without extraction, report partial
  source retention, not completed ingestion. Do not invent a Knowledge media
  tool or add a connector or service.
- **Social posts:** retain available thread context and a direct original URL in
  citations. Do not invent inaccessible replies or context.
- **Conversations and chat exports:** use `knowledge-source-ingest` for
  acquisition and overlap handling when needed, then continue with the retained
  snapshot. Read substantive discussions with replies and surrounding context;
  adjacent messages may belong to different threads. Preserve stable message and
  author IDs, dates and original labels. Distinguish authors, addressed
  participants and third-party mentions; a mention or reaction is not a
  statement by that person. File durable material by subject and reuse existing
  pages; do not create a page per message or profile every channel member. A
  digest can orient the reader, but apply the entity, claim and source-note
  steps to the underlying discussions too.

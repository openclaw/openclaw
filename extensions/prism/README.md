# OpenClaw Prism Provider

Official OpenClaw provider plugin for Prism's OpenAI-compatible inference API.

## Install

```bash
openclaw plugins install @openclaw/prism-provider
openclaw onboard --auth-choice prism-api-key
```

Select models with refs such as `prism/deepseek-v4.1-flash`.

See the [Prism provider documentation](../../docs/providers/prism.md) for model
capabilities and non-interactive setup.

# Research qualification

Contract fixtures are deterministic regressions, not model-quality evaluations.
The initial fixtures cover exact citations, missing/negating evidence, copied
sources, numerical units/dates/derivations, inaccessible sources, and source
instruction injection. None measures live support precision or research parity.

Before claiming broad quality, run a 40-task development pilot covering lookup,
enumeration, comparison tables, current technical questions, conflicting
analytical reports, literature mapping, supplied documents, and adversarial
sources. Keep separately held-out tasks; predeclare budgets, source snapshots,
models, auth routes, evaluator versions, and human-audited support criteria.
Record citation support precision and answer coverage separately. Report missing
usage as unknown. Do not count repeated/copied URLs as independent corroboration.
No benchmark data or paid evaluation is bundled or silently executed.

Each route has its own qualification record: portable direct API, provider-managed
research, Codex API key, Codex OAuth, and ChatGPT plan-usage/token sharing are not
interchangeable. This feature does not implement a Codex research RPC or a private
OAuth backend. Contract tests do not qualify live credentials or managed-service
retention, cancellation, billing, latency, or model quality.

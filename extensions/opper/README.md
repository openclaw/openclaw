# OpenClaw Opper Provider

Official OpenClaw provider plugin for [Opper](https://opper.ai), a European AI
gateway: one OpenAI-compatible API key for 700+ models from 50+ providers.
Discovery lists the models your key can route to, each once by its bare model name.

Opper is bundled with OpenClaw and releases together with the host. No separate
plugin installation is required.

Configure it through onboarding:

```bash
openclaw onboard --auth-choice opper-api-key
```

See <https://docs.openclaw.ai/providers/opper> for setup and configuration.

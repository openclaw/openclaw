# OpenClaw glossary

The single source for product terms in UI, channel and CLI messages, and docs. Each row has **Use**, **Meaning**, and **Avoid for this meaning**. A phrase in the last column is scoped to that row's meaning. Commands, code identifiers, quoted source evidence, and unrelated technical uses keep their exact spelling. A dash in Avoid means no competing name is listed.

Look up the relevant rows rather than loading the whole file. From the repository root, run `node .agents/skills/openclaw-writing/scripts/glossary.mjs lookup "checkout" "owner"`. Lookups search Use and Avoid, return all matching meanings, and report misses. Change or add an entry in the same PR when copy exposes a confusing or missing term. Ordinary team review applies, with no separate approval gate.

## The product

| Use        | Meaning                                                                                                                                                                             | Avoid for this meaning                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| OpenClaw   | The product: an AI assistant that runs on your own computer and works in the channels you already use. Write `openclaw` in lowercase only for the command, the package, and config. | Openclaw, Open Claw                                                                                     |
| Gateway    | The OpenClaw service that runs agents, connects channels, and keeps sessions. Its host machine is “the computer running OpenClaw”.                                                  | gateway (lowercase for the service), server (for this service)                                          |
| Claw       | One OpenClaw install opened through OpenClaw ID, with its own name and address.                                                                                                     | claw (lowercase for the install)                                                                        |
| Control UI | The OpenClaw app you open in a browser to chat with agents, manage sessions, and change settings.                                                                                   | web app, dashboard (for the whole app), web dashboard, the OpenClaw app (when the browser app is meant) |
| dashboard  | A page of widgets that an agent builds for a session, shown beside the chat.                                                                                                        | board                                                                                                   |
| portal     | A live preview of an app that an agent is running, opened from the Control UI.                                                                                                      | —                                                                                                       |
| Labs       | The Settings page for experimental features, which may change, break, or disappear between releases.                                                                                | —                                                                                                       |
| settings   | The options that control how OpenClaw behaves, changed under Settings in the Control UI. Say "config file" only for the file itself.                                                | config, configuration                                                                                   |

## Agents and sessions

| Use               | Meaning                                                                                                                                                                                                                                                  | Avoid for this meaning                                                   |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| agent             | An AI worker with its own name, instructions, workspace, and tools. You talk to an agent in a session.                                                                                                                                                   | assistant                                                                |
| session           | The container a chat with an agent lives in, including its messages, agent, and work location. In a channel, address the reader's exchange as “this chat”.                                                                                               | conversation, thread                                                     |
| chat              | The exchange of messages with an agent. Use “this chat” when addressing someone in a channel, and session for the container.                                                                                                                             | conversation, transcript                                                 |
| chat history      | The saved record of the messages in a session. "Chat" is the exchange itself.                                                                                                                                                                            | transcript (for an ordinary chat), session history, conversation history |
| reply             | What an agent sends back after a message, including the work it does on the way.                                                                                                                                                                         | response, turn                                                           |
| subagent          | An agent that another agent starts to do part of its work.                                                                                                                                                                                               | child chat, sub-agent                                                    |
| side chat         | A separate chat beside a session where you ask questions about that session without interrupting the agent.                                                                                                                                              | —                                                                        |
| goal              | An objective a session keeps working toward until it is done or cleared.                                                                                                                                                                                 | —                                                                        |
| queued message    | A message waiting to be delivered to the agent. A paused or held message may need an explicit action before delivery, so queued does not promise it will run automatically.                                                                              | follow-up message (when naming the queued item)                          |
| steer             | To send a message that changes the direction of the reply an agent is working on now.                                                                                                                                                                    | guide                                                                    |
| incognito session | A session whose OpenClaw chat history is kept in memory and expires after 24 hours or a Gateway restart. This does not make tool writes, uploads, or harness diagnostics ephemeral. Codex can still store submitted messages in its diagnostic database. | —                                                                        |
| compaction        | Summarizing the older part of a long chat so the session stays within the model's limit and can continue.                                                                                                                                                | —                                                                        |
| workspace         | The folder where an agent works. The Git-specific Worktree option creates a separate workspace. Use Worktree when naming that option, not as another name for the folder.                                                                                | checkout, working directory                                              |
| Worktree          | The Git option that creates a separate workspace. For example: “Choose Worktree to create a separate workspace.”                                                                                                                                         | —                                                                        |
| automation        | Work an agent does on a schedule or when something happens, without you sending a message.                                                                                                                                                               | cron job, job, scheduled task, heartbeat                                 |
| Template          | A ready-made agent you can add, packaged with its instructions, skills, plugins and automations.                                                                                                                                                         | template (lowercase, for this feature)                                   |

## People and access

| Use               | Meaning                                                                                                                                                                                                                                                                                       | Avoid for this meaning                                                                                                                                                                 |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| admin             | A person allowed to administer a Gateway. Translate an internal owner label to admin only when the actual check requires administrative access. A channel owner allowlist does not grant global admin access. An admin is not automatically the OpenClaw ID Claw owner who can invite people. | administrator, command owner (only for an admin check), bot owner (only for an admin check), owner authority (only for an admin check), operator (only when it means an administrator) |
| access            | What a person or device is allowed to see or do. Name the level and scope required, such as read access to a run or write access to a session.                                                                                                                                                | —                                                                                                                                                                                      |
| read access       | Access to view the relevant information. Session read access does not imply access to all Gateway data.                                                                                                                                                                                       | operator.read, operator.sessions.read (as reader-facing labels)                                                                                                                        |
| write access      | Access to change or send in the relevant area. Write access to a session is not Gateway administration.                                                                                                                                                                                       | operator.write, operator.sessions.write (as reader-facing labels)                                                                                                                      |
| Admin access      | The device setup level that permits administrative actions. Keep it distinct from an agent's Full access permission mode.                                                                                                                                                                     | Full access (for the device setup level)                                                                                                                                               |
| role              | A named set of access rights for a person. Role names do not replace checking the specific permission required for an action.                                                                                                                                                                 | —                                                                                                                                                                                      |
| Teammate          | The non-admin preset role formerly labeled Operator. It allows the access assigned to that role, not unrestricted administration.                                                                                                                                                             | Operator (the non-admin preset role label), admin (for this role)                                                                                                                      |
| guest             | A person invited with limited access. The invitation and assigned role determine what they can see and do.                                                                                                                                                                                    | visitor                                                                                                                                                                                |
| creator           | The person who started a session. Creator authority controls session sharing where the product permits it. Assigning a different session owner does not transfer that authority.                                                                                                              | owner (when naming who created the session or controls its sharing)                                                                                                                    |
| owner             | The person or agent currently responsible for a session. Assignment grants no additional access.                                                                                                                                                                                              | creator (for the current assignee)                                                                                                                                                     |
| automation owner  | The person responsible for an automation, who can manage their own automation within its access rules. Ownership grants neither host-command access nor general admin access.                                                                                                                 | admin (solely because someone owns an automation)                                                                                                                                      |
| Claw owner        | The OpenClaw ID owner who holds ownership authority for a Claw and can invite people. This is distinct from a session owner or Gateway admin.                                                                                                                                                 | owner (without Claw in this context), admin (for this ownership)                                                                                                                       |
| shared connection | A connection using the shared Gateway secret rather than a person's individual sign-in. Its granted access is shared, not a named session owner.                                                                                                                                              | Shared owner                                                                                                                                                                           |
| permissions       | What an agent may read, edit, and run in a session. The modes are Read only, Ask me, Auto-review, and Full access. People and devices have access instead.                                                                                                                                    | permission mode, execution permissions (for this control)                                                                                                                              |
| Full access       | The agent permission mode that permits work without routine approval prompts, subject to remaining security checks. It is not the device setup level.                                                                                                                                         | Admin access (for the agent mode)                                                                                                                                                      |
| access request    | A request from a person or device to obtain access or extend the access it has. An agent action awaiting permission is an approval.                                                                                                                                                           | approval (when it obscures a person or device access request)                                                                                                                          |
| public access     | Making a session readable by anyone with its public link, without signing in. Session sharing among signed-in people is separate.                                                                                                                                                             | world-readable, public share                                                                                                                                                           |
| approval          | A request for a person to allow or deny something an agent wants to do, before it happens.                                                                                                                                                                                                    | exec approval                                                                                                                                                                          |
| sign in           | The action of proving who you are to OpenClaw or a provider. Sign-in is the noun for that action or its status. A stored provider connection is an account.                                                                                                                                   | log in, login, re-auth, authenticate                                                                                                                                                   |
| pair              | To approve a connection to OpenClaw. Say DM pairing for admitting a sender and device pairing for connecting hardware or a browser, because they grant different access.                                                                                                                      | —                                                                                                                                                                                      |
| DM pairing        | Approval for a person to send direct messages to an agent through a channel. It does not pair their hardware with the Gateway.                                                                                                                                                                | device pairing (for admitting a DM sender)                                                                                                                                             |
| device pairing    | Approval for a device or browser to connect to a Gateway with specified access. It does not authorize an unrelated sender to DM an agent.                                                                                                                                                     | node pairing (in reader-facing copy)                                                                                                                                                   |
| OpenClaw ID       | The optional sign-in service that lets you open your OpenClaw from other devices and invite people, without opening a port. The feature it provides is called remote access.                                                                                                                  | —                                                                                                                                                                                      |
| recovery kit      | The file you save when you turn on remote access. You need it to get back in if you lose every approved device.                                                                                                                                                                               | —                                                                                                                                                                                      |
| Gateway secret    | The token or password a browser or app uses to connect to a Gateway.                                                                                                                                                                                                                          | Gateway token, auth token                                                                                                                                                              |

## Models

| Use            | Meaning                                                                                                                                                                                     | Avoid for this meaning                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| model provider | The company or service that runs a model. Use its verified display name when known, otherwise model provider. Provider is enough after the first mention. A model itself is not a provider. | AI service, API provider, LLM (for the provider)                             |
| account        | A saved way for OpenClaw to use a provider: a sign-in or an API key.                                                                                                                        | saved login, saved sign-in, auth profile, credential                         |
| primary model  | The model an agent uses unless a session picks another.                                                                                                                                     | default model                                                                |
| fallback model | A model OpenClaw switches to when the primary model cannot reply.                                                                                                                           | —                                                                            |
| utility model  | The model used for short auxiliary work, such as setup or session summaries. It need not be smaller than the primary model.                                                                 | —                                                                            |
| effort         | The setting for how much work a model puts into a reply. Visible reasoning text is a different concept.                                                                                     | thinking level, thinking (for the setting), reasoning (for the effort level) |
| harness        | The program running an agent's replies, such as OpenClaw's own or an installed coding agent. This is distinct from the model provider and from a language runtime.                          | runtime, CLI backend                                                         |

## Extending OpenClaw

| Use            | Meaning                                                                                                                           | Avoid for this meaning                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| plugin         | An add-on that gives OpenClaw capabilities such as channels, model providers, or tools. A Chrome extension is still an extension. | extension, integration                |
| skill          | A set of instructions an agent loads when a task calls for it.                                                                    | —                                     |
| Skill Workshop | The page where you review, edit, and undo the skills an agent learned from its work.                                              | —                                     |
| tool           | An action an agent can take, such as reading a file, searching the web, or running a command.                                     | —                                     |
| MCP server     | An outside service that gives agents extra tools through the Model Context Protocol.                                              | server (on its own)                   |
| channel        | A messaging app that OpenClaw is connected to, such as Discord, Slack, Telegram, or WhatsApp.                                     | messaging app (as the term), chat app |
| ClawHub        | The public catalog where you find and install skills, plugins, and Templates.                                                     | the registry                          |

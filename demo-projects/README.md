# OpenClaw Quick Demo Lab

Ba prototype độc lập trong thư mục `demo-projects/`:

1. Trợ lý học tập mini — chat với câu trả lời mẫu về Python/C++.
2. Quiz IT — trắc nghiệm 3 câu và chấm điểm ngay trên trình duyệt.
3. Gợi ý sản phẩm — lọc dữ liệu mẫu theo ngân sách và nhu cầu.

## Chạy thử
Mở `index.html` trong trình duyệt, hoặc mở thư mục trong VS Code và dùng Live Server.

## Giới hạn
Đây là bản demo frontend, chưa gọi mô hình AI, chưa kết nối OpenClaw Gateway, không có backend hay thanh toán. Chat không lưu lịch sử và điểm quiz sẽ đặt lại khi tải lại trang.

## Có thể phát triển tiếp
- Thêm backend để gọi mô hình AI an toàn.
- Tìm hiểu cơ chế xác thực trước khi tích hợp OpenClaw Gateway.
- Lưu tiến độ quiz và lấy dữ liệu sản phẩm từ API.

Không đặt khóa API hoặc mật khẩu trong mã frontend hay repository công khai.
